# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features
- Play against the computer
- Score tracking (wins, losses, ties)
- Score persists across page reloads using localStorage
- Reset button to clear your score

## How to play
Open the live demo and click Rock, Paper, or Scissors to play against the computer.
